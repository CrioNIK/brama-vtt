# Współtworzenie BRAMA VTT

[English](../../CONTRIBUTING.md) · [Українська](../uk/CONTRIBUTING.md) · [Español](../es/CONTRIBUTING.md) · [Polski](CONTRIBUTING.md) · [Čeština](../cs/CONTRIBUTING.md)

To tłumaczenie [nadrzędnego dokumentu angielskiego](../../CONTRIBUTING.md).

Chętnie przyjmuję zgłoszenia błędów, poprawki dostępności, tłumaczenia i zmiany o konkretnym zakresie. Przed wdrożeniem dużej zmiany otwórz zgłoszenie opisujące problem i zamierzone zachowanie.

1. Przeczytaj [LICENSE.md](LICENSE.md) i [oryginalną licencję angielską](../../LICENSE.md). Zgłaszaj tylko materiały, do których wniesienia masz prawo. Wkład podlega licencji projektu; jego zgłoszenie nie przenosi praw autorskich ani nie przyznaje automatycznego wyjątku komercyjnego.
2. Używaj Node.js w wersji co najmniej 24.12 w ramach gałęzi 24.x i uruchom `npm ci`.
3. Zachowaj jednoznaczne kontrakty danych, kontrole uprawnień i zachowanie poleceń. Nie tłumacz zapisanych treści użytkowników ani nie zmieniaj technicznych kluczy protokołu na lokalizowane słowa.
4. Dodaj lub zaktualizuj angielskie klucze komunikatów i wartości we wszystkich pięciu językach. Zachowaj nazwane symbole zastępcze. Opisz zachowanie w oryginalnej dokumentacji angielskiej i zaktualizuj jej wersje ukraińską, hiszpańską, polską i czeską.
5. Uruchom `npm test`, `npm run typecheck` i `npm run build`. Sprawdź zmienione interfejsy przy szerokościach typowych dla komputerów oraz wąskich okien, w tym obsługę klawiatury i błędy.
6. W pull requeście opisz problem, wynikowe zachowanie, weryfikację i pozostałe ograniczenia. Nie dołączaj danych uwierzytelniających, prywatnych danych kampanii, baz danych, skopiowanych treści komercyjnych ani wygenerowanych katalogów zależności.

Sprawdzam wkład jako **CrioMant / CrioNIK**. Włączenie do projektu jest decyzją wynikającą z przeglądu technicznego i nie stanowi zgody na użytek komercyjny.
