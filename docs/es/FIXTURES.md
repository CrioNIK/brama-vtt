# Datos de pruebas de regresión

[English](../../tests/fixtures/README.md) · [Українська](../uk/FIXTURES.md) · [Español](FIXTURES.md) · [Polski](../pl/FIXTURES.md) · [Čeština](../cs/FIXTURES.md)

Esta es una traducción del [documento principal en inglés](../../tests/fixtures/README.md). Los datos de prueba se encuentran en [tests/fixtures](../../tests/fixtures).

Estos documentos neutrales y autónomos ponen a prueba el contrato de intercambio que admite la aplicación. Los contenedores de archivo incluyen JSON sintético mínimo y los hashes correspondientes. No contienen extensiones ejecutables, paquetes de aplicaciones, credenciales de sesión ni archivos de recursos de juegos.

Las pruebas modifican copias para comprobar el rechazo, la atomicidad, la privacidad y la reasignación de referencias. Estos datos de prueba no afirman una interoperabilidad comprobada en un entorno real con todas las aplicaciones externas o revisiones de formato. Los identificadores técnicos de formato se mantienen sin cambios porque forman parte del esquema de intercambio.
