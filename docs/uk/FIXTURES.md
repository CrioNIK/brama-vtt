# Дані регресійних тестів

[English](../../tests/fixtures/README.md) · [Українська](FIXTURES.md) · [Español](../es/FIXTURES.md) · [Polski](../pl/FIXTURES.md) · [Čeština](../cs/FIXTURES.md)

Це переклад [основного англійського документа](../../tests/fixtures/README.md). Тестові дані містяться в [tests/fixtures](../../tests/fixtures).

Ці самодостатні нейтральні документи перевіряють підтримуваний застосунком контракт обміну даними. Архівні оболонки містять мінімальний синтетичний JSON і відповідні хеші. Вони не містять виконуваних розширень, комплектів застосунків, облікових даних сесій або архівів ігрових ресурсів.

Тести змінюють копії, щоб перевірити відхилення, атомарність, приватність і перепризначення посилань. Ці тестові дані не стверджують наявності перевіреної в реальному середовищі сумісності з кожним зовнішнім застосунком або версією формату. Технічні ідентифікатори форматів залишаються незмінними, оскільки вони є частиною схеми обміну.
