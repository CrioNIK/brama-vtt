# Участь у розробці BRAMA VTT

[English](../../CONTRIBUTING.md) · [Українська](CONTRIBUTING.md) · [Español](../es/CONTRIBUTING.md) · [Polski](../pl/CONTRIBUTING.md) · [Čeština](../cs/CONTRIBUTING.md)

Це переклад [основного англійського документа](../../CONTRIBUTING.md).

Я вітаю повідомлення про помилки, поліпшення доступності, переклади та цілеспрямовані зміни. Перед реалізацією великої зміни відкрийте issue з описом проблеми й очікуваної поведінки.

1. Прочитайте [LICENSE.md](LICENSE.md) та [оригінальну англійську ліцензію](../../LICENSE.md). Подавайте лише матеріали, на внесення яких маєте право. На внески поширюється ліцензія проєкту; їх подання не передає авторського права й не надає автоматичного винятку для комерційного використання.
2. Використовуйте Node.js версії 24.12 або новішої в межах гілки 24.x і виконайте `npm ci`.
3. Залишайте контракти даних, перевірки дозволів і поведінку команд явними. Не перекладайте збережений користувацький вміст і не замінюйте технічні ключі протоколу локалізованими словами.
4. Додавайте або оновлюйте англійські ключі повідомлень і значення всіма п’ятьма мовами. Зберігайте іменовані плейсхолдери. Описуйте поведінку в оригінальній англійській документації та оновлюйте її українську, іспанську, польську й чеську версії.
5. Виконайте `npm test`, `npm run typecheck` і `npm run build`. Перевірте змінені інтерфейси за звичайної та вузької ширини вікна, зокрема взаємодію з клавіатури й помилки.
6. У pull request опишіть проблему, отриману поведінку, перевірку та обмеження, що залишилися. Не додавайте облікові дані, особисті дані кампаній, бази даних, скопійований комерційний вміст або згенеровані каталоги залежностей.

Я перевіряю внески під ім’ям **CrioMant / CrioNIK**. Включення до проєкту є рішенням за результатами технічної перевірки й не надає дозволу на комерційне використання.
