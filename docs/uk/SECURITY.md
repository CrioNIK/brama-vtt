Це переклад [основного англійського документа](../../SECURITY.md).

Наразі BRAMA призначена для локального використання. Вона прив’язується до інтерфейсу loopback, зберігає облікові дані сесії у вкладці браузера та стан кампанії в SQLite. Застосунок не є інтернет-сервісом облікових записів. Не відкривайте сервер розробки безпосередньо для загальнодоступного Інтернету.

Сервер перевіряє команди й фільтрує приватні дані для кожного учасника. Володіння токеном, доступ до аркуша персонажа, доступ до журналу й одержувачі показу — це окремі дозволи. Клієнтський інтерфейс не є межею безпеки. HTML очищується; імпортовані архіви є неактивними даними, а не виконуваними розширеннями.

Якщо ви підозрюєте вразливість, скористайтеся приватним повідомленням про вразливості GitHub, якщо воно доступне в цьому репозиторії. Інакше відкрийте issue із запитом на приватний контакт, не публікуючи подробиць експлуатації або приватних даних. Укажіть уражені версії, мінімальний приклад відтворення із синтетичними даними, очікувану й фактичну поведінку та вплив. Ніколи не додавайте токени сесій, коди запрошень, робочі бази даних або матеріали чужих кампаній.

Для цього раннього випуску не гарантовано строку відповіді або періоду довгострокової підтримки. Створюйте резервні копії локальних даних і переглядайте зміни перед оновленням.
