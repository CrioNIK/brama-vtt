# Data regresních testů

[English](../../tests/fixtures/README.md) · [Українська](../uk/FIXTURES.md) · [Español](../es/FIXTURES.md) · [Polski](../pl/FIXTURES.md) · [Čeština](FIXTURES.md)

Toto je překlad [hlavního anglického dokumentu](../../tests/fixtures/README.md). Testovací data jsou ve složce [tests/fixtures](../../tests/fixtures).

Tyto samostatné neutrální dokumenty prověřují výměnný kontrakt podporovaný aplikací. Archivní obálky obsahují minimální syntetický JSON a odpovídající hashe. Neobsahují spustitelná rozšíření, balíčky aplikací, přihlašovací údaje relací ani archivy herních prostředků.

Testy upravují kopie, aby ověřily odmítnutí, atomicitu, soukromí a přemapování odkazů. Tato testovací data nejsou tvrzením o interoperabilitě ověřené v reálném prostředí s každou externí aplikací nebo revizí formátu. Technické identifikátory formátů zůstávají beze změny, protože jsou součástí výměnného schématu.
