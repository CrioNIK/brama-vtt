# Přispívání do BRAMA VTT

[English](../../CONTRIBUTING.md) · [Українська](../uk/CONTRIBUTING.md) · [Español](../es/CONTRIBUTING.md) · [Polski](../pl/CONTRIBUTING.md) · [Čeština](CONTRIBUTING.md)

Toto je překlad [hlavního anglického dokumentu](../../CONTRIBUTING.md).

Uvítám hlášení chyb, zlepšení přístupnosti, překlady a změny s jasným zaměřením. Před realizací rozsáhlé změny otevřete issue s popisem problému a zamýšleného chování.

1. Přečtěte si [LICENSE.md](LICENSE.md) a [původní anglickou licenci](../../LICENSE.md). Předkládejte pouze materiály, které máte právo poskytnout. Příspěvky používají licenci projektu; jejich předložení nepřevádí autorská práva ani automaticky neuděluje komerční výjimku.
2. Používejte Node.js 24.12 nebo novější v řadě 24.x a spusťte `npm ci`.
3. Zachovejte výslovné datové kontrakty, kontroly oprávnění a chování příkazů. Nepřekládejte uložený uživatelský obsah ani nenahrazujte technické klíče protokolu lokalizovanými slovy.
4. Přidejte nebo aktualizujte anglické klíče zpráv a hodnoty ve všech pěti jazycích. Zachovejte pojmenované zástupné symboly. Chování zdokumentujte v původní anglické dokumentaci a aktualizujte její ukrajinskou, španělskou, polskou a českou verzi.
5. Spusťte `npm test`, `npm run typecheck` a `npm run build`. Ověřte dotčená rozhraní při šířce pro stolní počítač i v úzkém okně, včetně ovládání klávesnicí a chyb.
6. V pull requestu popište problém, výsledné chování, ověření a zbývající omezení. Nepřikládejte přihlašovací údaje, osobní data kampaní, databáze, zkopírovaný komerční obsah ani vygenerované složky závislostí.

Příspěvky kontroluji pod jménem **CrioMant / CrioNIK**. Začlenění do projektu je rozhodnutím technické kontroly a neuděluje svolení ke komerčnímu použití.
